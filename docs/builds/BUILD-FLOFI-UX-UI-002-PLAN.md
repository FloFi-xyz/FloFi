## Bounded decision (not implemented)

Executing a chat request without opening FloFi would need either an in-chat signer (hosts and Telegram offer none to FloFi; MCP in-frame signing is disabled pending host security review) or a standing delegated authority for ad-hoc conversational requests. The only delegated authority today is the owner's automation delegation (passkey-bounded, MOCKED evidence, production signing blocked by no-custody). Extending it to chat requests is a new authorization model and needs an owner decision; see the report.
