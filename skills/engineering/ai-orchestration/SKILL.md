# AI orchestration

- Read runtime settings, provider adapters and model compatibility together. FloFi resolves the configured OpenAI or Anthropic provider and its own credentials. Environment bootstrap uses OpenAI where configured. Active settings or a provider failure never silently reroute requests to the other provider. Exact grammar is the deterministic fallback when applicable. No LiteLLM gateway is implemented in the reviewed runtime. Keep gateway retries and cost accounting separate if evaluating gateway designs. [Runtime resolution](../../../apps/reference-dapp/src/server/copilot-runtime.ts) · [Provider adapters](../../../apps/reference-dapp/src/server/copilot-providers.ts)
- Check runtime-specific model parameters, output schema and abstention, refusal and invalid-output handling. V2 supports bounded, allowlisted catalog tools and validates the final intent even when the provider carries a structured-output schema. Preserve canonical chain/asset slots and account/workflow/revision continuity across follow-ups. Treat messages, tool results and provider-returned fields as untrusted. Model text can describe or propose a workflow. Deterministic composition, capability checks, Review and applicable wallet authority control execution. [Copilot service](../../../apps/reference-dapp/src/server/copilot-service.ts) · [V2 regressions](../../../apps/reference-dapp/src/server/copilot-service-v2.test.ts)
- Anthropic schema complexity selects constrained output or a prompted, byte-stable ephemeral-cache prefix. Strict tools can remain when their schemas fit independently. FloFi validates the final object in either mode. Bound provider deadlines, tool rounds and tokens. The reconnect retry applies to the settings read. Malformed and rate-limited provider responses supply bounded user-facing failures and retry guidance, without an automatic model retry. Keep stale/canceled responses from applying client changes. Measure latency and cache categories by actual provider and response model. Separate logical requests from provider attempts and tool rounds.
