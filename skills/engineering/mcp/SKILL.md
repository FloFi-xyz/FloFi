# Model Context Protocol

- MCP separates JSON-RPC transport and capability discovery from tools, resources and prompts. FloFi's hosted gateway uses stateless Streamable HTTP. Its compatibility tests cover the 2025-06-18 and 2025-11-25 handshakes and the 2026-07-28 modern envelope. Check headers, method/name, capability negotiation and response shape for the client under test. FloFi advertises its registered tools and conditional panel resource. Stdio, arbitrary resources or prompts and host-specific UI support need separate implementation evidence. MCP Apps panel protocol metadata is a separate contract. [Gateway](../../../apps/reference-dapp/src/mcp/gateway.ts) · [Protocol tests](../../../apps/reference-dapp/src/mcp/gateway.test.ts) · [Tool registrations](../../../apps/reference-dapp/src/mcp/tools.ts)
- Check OAuth 2.1 PKCE, protected resource metadata and challenge, resource audience, client/redirect binding, scopes, expiry, origin and revocation. Bound client metadata lookup and rate limits. Distinguish OAuth grant, transport lifecycle, FloFi account and wallet ownership. Allowlisted tools, strict schemas and server-side authorization remain necessary even when host annotations look safe. [OAuth](../../../apps/reference-dapp/src/mcp/oauth/server.ts) · [OAuth tests](../../../apps/reference-dapp/src/mcp/oauth/gateway-oauth.pg.test.ts)
- ChatGPT and Claude are external host integration targets. Verify hosted client acceptance separately from loopback protocol tests. Discover capabilities and retain the browser handoff where the host lacks the approved panel. Treat model text, tool arguments and provider data as untrusted. An inert browser reference needs the original requesting-account session or proven owner recovery. A private panel capability belongs only in approved metadata and has its own expiry, workflow hash, tenant and wallet checks. Recompose the canonical workflow, validate fresh proof and show exact Review before wallet authorization. Host approval or a tool invocation grants no financial authority. [Host and handoff runbook](../../../docs/deploy/MCP.md) · [Approval service](../../../apps/reference-dapp/src/mcp/handoff/service.ts) · [Link integrity](../../../apps/reference-dapp/src/mcp/link-integrity.pg.test.ts)
- Apply operation-specific idempotency and bounded deadlines. Test cross-account status denial, callback replay, duplicate handoffs, timeout/unknown state and host-specific capability fallbacks. Report uncertainty without replaying mutations or claiming completion.
