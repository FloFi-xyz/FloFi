# Account abstraction

- EIP-7702 designates delegate code for an EOA and can clear the designation. ERC-4337 validates and executes a UserOperation through a versioned EntryPoint, with a bundler submitting the enclosing transaction. These mechanisms can coexist. Keep the EOA transaction/authorization nonce, EntryPoint nonce key and sequence, and any ERC-20 permit nonce separate. A transaction hash, UserOperation hash and bundler response prove different things. [Bundler](../../../apps/reference-dapp/src/user-funded/bundler.ts) · [EVM reconciliation](../../../apps/reference-dapp/src/user-funded/evm-reconcile.ts)
- Pin chain, account, delegate code, EntryPoint version, reviewed call set, nonce and gas bounds. Read delegation state live. Check every typed-data domain and digest before signing. EIP-7702 allows a chain-zero signature at protocol level. FloFi's eligible upgrade path requires the exact reviewed chain, pinned delegate, fresh nonce, separate consent and signature. Refuse incompatible, pending or different delegation. Use fresh Review when a material change invalidates the commitment. Circle can continue the same verified v0.8 UserOperation without reusing the consumed upgrade authorization if the exact reviewed delegate is already installed. [Configuration](../../../apps/reference-dapp/src/user-funded/config.ts) · [Circle path](../../../apps/reference-dapp/src/user-funded/circle-gas.ts) · [Circle upgrade regressions](../../../apps/reference-dapp/src/user-funded/circle-flofi-wallet.test.ts)
- The native reviewed ERC-4337 group path uses v0.7. Circle's conditional path pins eligible MetaMask DeleGator v0.7 on Base/Arbitrum and Simple7702Account v0.8 on Ethereum/Base/Arbitrum. Verify actual wallet compatibility and per-flow eligibility, exact artifact simulation and pinned bundler/EntryPoint. Reconcile the specific operation and execution logs before advancing the run or opening a fresh attempt after uncertainty. [Circle eligibility](../../../apps/reference-dapp/src/user-funded/circle-gas.ts) · [Bundler regressions](../../../apps/reference-dapp/src/user-funded/circle-bundler.test.ts)
- Account code and bundler infrastructure change the transaction mechanism. Embedded versus external wallets describes wallet infrastructure, and custody concerns control of signing keys. Each is separate from the user's financial authorization. Legacy executor-funded delegation is read/revoke only. A wallet-relayed ERC-20 receipt may preserve the owner's transaction nonce and uses the [transfer skill's](../token-transfers/SKILL.md) proof path.
