# Wallet infrastructure

- FloFi Wallet uses Privy embedded wallets. External EVM discovery uses EIP-6963 announcements and an EIP-1193 legacy fallback. Bind the exact provider object, account and chain across connection, wallet events and network switching. External Solana uses Wallet Standard account and feature discovery. Recheck wallet state after reconnect, account change, switch or network error. Classify generic hardware wallets by the verified provider, chain and signing-feature combination. This repository has no basis for a dedicated Ledger/Trezor integration claim. Legacy Turnkey records have an export path only. [EVM discovery](../../../apps/reference-dapp/src/wallet/evm-discovery.ts) · [Solana wallet](../../../apps/reference-dapp/src/wallet/solana-wallet.ts) · [Account model](../../../apps/reference-dapp/src/accounts/account-model.ts)
- Keep OAuth identity, FloFi account/session, linked wallet identity and signing authority separate. Use server-verified Privy identity and provider verification time. A refreshed JWT by itself supplies no new authentication timestamp. External EVM SIWE and Solana SIWS prove wallet ownership with a fresh single-use signing input. Privy proof consumption is also bound to the provider session. Link explicitly within the short method-linking window. A matching email does not merge accounts or transfer an already linked wallet. Duplicate recovery requires proof of both accounts and the existing empty-duplicate disposition. Reauthenticate or refuse mismatch and stale sessions. [Provider verification](../../../apps/reference-dapp/src/accounts/privy-server.ts) · [Account linking and recovery](../../../apps/reference-dapp/src/accounts/account-service.ts) · [External wallet sessions](../../../apps/reference-dapp/src/app/wallet-session-action.ts)
- Keep credentials and key material inside the designated provider boundaries. Engineering review uses identities, statuses and redacted evidence. Use the verified wallet UI for export/recovery and explicit wallet confirmation for each applicable Review. OAuth, embedded login and account linking grant no signing permission by themselves. Use the [execution skill](../execution/SKILL.md) for exact-byte handoff. Verify wallet-switch/mismatch, rejected or stale proofs, duplicate account recovery and EVM/Solana isolation.
